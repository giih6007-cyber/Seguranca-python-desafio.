# Seguranca-python-desafio.
"Simulação de Ransomware e keylogger para fins educacionais".
🛡️ Projeto de Segurança: Ransomware & Keylogger
Este projeto demonstra como ameaças cibernéticas funcionam na prática usando Python.

O que foi feito:
Ransomware: Implementei um sistema de criptografia simétrica usando a biblioteca cryptography. O código gera uma chave única, bloqueia o arquivo e só permite o acesso com a chave correta.

Keylogger: Criei um script que monitora eventos de teclado e registra as entradas em um arquivo .txt, simulando o roubo de informações.

Como se proteger:
Backup: Ter cópias de segurança fora da rede impede que o Ransomware cause danos permanentes.

Antivírus: Ferramentas modernas detectam o comportamento de keyloggers (monitoramento de teclado) e bloqueiam a execução.

Educação: Nunca baixar scripts ou executáveis de fontes desconhecidas.
